# MELK Studio v1.0.8 — Scene Hardware Mapping (Experimental)

Studio > My Scenes > Hardware opens a mapping dialog for any scene (Candle, Party, Sleep, etc). Pick controller Mode 128–155. Selecting a linked scene runs the chosen native hardware pattern instead of phone-driven colour steps. Removing the mapping restores original scene behaviour. No arbitrary custom effects are saved to controller. Mode 128 is user-confirmed power-cycle persistent; other numbered modes must be tested. Smart Auto time-based switching still runs on phone. Bluetooth transport, scan, auto reconnect and native OTA plugin code unchanged.

Test OTA and strip connection before normal use. Save a working APK backup.
