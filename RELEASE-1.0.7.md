# MELK Studio v1.0.7 – Hardware Effects Library and OFF fix

- Built-in modes 128–155 listed as hardware effects; Mode 128 marked as user-verified across app close and power cycle. Remaining modes are untested until marked by the user.
- Built-in mode editor permits marking a mode verified after real-world testing; filter to only offline-tested modes.
- Power OFF stops software animations, disables Smart Auto, cancels transitions and clears pending queued writes before sending OFF.
- Phone-driven Candle/Party effects do NOT persist autonomously; mapping them to a hardware mode selects that hardware pattern, not an identical custom animation.
- Bluetooth adapter, transport and native updater source unchanged.
- Actual on-device acceptance tests and OTA activation still required.
